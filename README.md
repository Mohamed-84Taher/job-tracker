# Job Application Tracker

A fast, offline-first Kanban board to organize your job search. Track every
application from Applied to Offer, set follow-up reminders, and see how your
search is going with a built-in stats dashboard. All data stays in your browser.

🔗 **Live demo:** <your-link-here>

## Features

- Drag-and-drop Kanban board (Applied → Interview → Offer → Rejected)
- Search, filters and sorting
- Stats dashboard with charts
- Follow-up reminders
- Dark mode
- JSON import/export
- Installable PWA with offline support

## Tech Stack

React · TypeScript · Vite · Tailwind CSS · dnd-kit · Zustand · Recharts · Vitest · GitHub Actions
